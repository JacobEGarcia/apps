Lake & Line Support

Lake & Line is an offline reader for Issue 01, Between the Lines.

Save or mark a story read

Use the bookmark control to save a story. At the end of a preview, choose Mark as Read. Both states remain on this device.

Search

Open Explore and search by title, section, neighborhood, deck, or studio byline. The section menu narrows the issue.

Data recovery

If the current reading snapshot cannot be decoded, the app restores the last valid backup when possible and preserves the unreadable bytes. If a valid backup can be opened but durable storage cannot be restored, the app opens it read-only and offers both the complete reading-data export and a preserved recovery copy. If no valid backup exists, editing is blocked until you export the recovery copy or delete all local data.

Export or delete

Settings can export the complete local JSON snapshot. It is not redacted. A preserved recovery copy may contain a valid backup or unreadable raw bytes. Delete All removes the current snapshot, backup, recovery bytes, and preferences.

Content boundary

Issue 01 contains original editorial sketches, not live news or reported journalism. Lake & Line is not affiliated with The Chicagoan, Chicago magazine, the CTA, or the City of Chicago.
