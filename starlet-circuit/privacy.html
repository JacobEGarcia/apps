Summary

Starlet Circuit is designed to work offline without an account or developer backend. The proposed App Store answer is Data Not Collected, subject to final audit of the signed archive, included SDKs, permissions, and runtime network behavior.

Data stored locally

The app stores local game progress in app-scoped iOS preferences. This can include coins, tickets, XP, unlocked racer identifiers, the selected racer, and tune levels. A primary snapshot, rolling backup, damaged-data recovery copy, and legacy migration keys may exist locally.

Starlet Circuit does not provide its own cloud service. Apple backup or device-transfer features may handle app data according to your Apple and iOS settings.

Recovery

If the primary snapshot is damaged, the app preserves those bytes. A valid local backup is restored when available. Without a valid backup, starter progress is displayed read-only so uncertain data is not overwritten; changes remain blocked until you explicitly erase all data.

JSON export

Export Progress JSON creates a full copy of current local progress through the iOS file exporter. You choose the destination. Review the file before sharing it. Once saved to an external provider or shared with another person, that destination or recipient controls the exported copy. The app does not automatically send exports to the developer.

Reset and erase

  • When storage is writable, Reset Progress starts fresh active progress. The prior primary can remain locally as the rolling backup, so Reset is not a complete privacy erasure.
  • Erase All Data removes primary, backup, recovery, and legacy local keys, then restores fresh progress.
  • Deleting the app is also subject to iOS and Apple backup behavior.

Commercial and network boundary

The inspected source contains no developer network client, account, analytics SDK, advertising SDK, tracking, cloud sync, purchase flow, or StoreKit. Local coins and tickets have no purchase path, prize, trade, cash value, or cash-out.

Device feedback

Starlet Circuit contains no audio in version 1.0. Optional haptics use local system feedback and are not developer collection.
