Ownfold support

Ownfold 1.0 requires an iPhone running iOS 17 or later. It works offline and does not require an account or subscription.

How do I capture something?

Tap the orange plus button and choose Note, Task, or Link. Add a title or first line, optionally file it in a Project or Area, then choose Save. Links require a complete http:// or https:// address.

What are Projects and Areas?

A Project is a result with a finish line. An Area is an ongoing part of life or work. Create and edit both from Library. Deleting a collection does not delete its entries: active entries return to the inbox and completed tasks remain completed.

How do connections work?

Type an entry title inside double brackets, such as [[Product standard]]. Ownfold matches titles without case or accent sensitivity and shows both outgoing links and backlinks. If several entries have the same exact title, every match is shown.

How do backup and restore work?

Settings can prepare a full JSON backup or readable Markdown export. A JSON restore is validated and previewed before you confirm replacement. Restore replaces the current workspace; export the current workspace first if you may want it again.

Why is the workspace read-only?

Ownfold detected data it could not safely validate or rewrite. It stops saving so the available bytes are not silently overwritten. Go to Settings, prepare and share the recovery copy, then use Delete all local data when you are ready to begin again.

Search and saved links

Search covers titles, body text, URLs, tags, collections, kind, and status. Ownfold does not fetch or preview saved websites. A link opens in the system browser only when you choose Open saved link.

Accessibility and appearance

Ownfold uses Dynamic Type, semantic controls, light and dark appearance, and motion reduction. If a control is difficult to use with VoiceOver, Voice Control, Switch Control, or a larger text size, include your device, iOS version, and the screen name when contacting support.

Delete everything

Settings → Delete all local data removes entries, collections, preferences, local backup/recovery files, and prepared exports after confirmation. Previously shared files remain wherever you sent them.
