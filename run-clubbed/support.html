Support · Version 1.0

Show up. Move. Keep an honest record.

Run Clubbed is a local run timer and planner for people you already run with.

Need help? Email jacobegarcia101@gmail.com. Include the app version, iOS version, and what you expected to happen. Never send health records, passwords, private meeting points, or an export you do not want to share.

Start a run

  1. Open Run and choose Solo Run or Club Run.
  2. Tap Start Run.
  3. Manually pause whenever you choose; paused time is excluded.
  4. Tap Finish, optionally enter known distance in kilometers, choose effort from 1–5, and save the receipt.

Plan a club commitment

  1. Open Club → Roster and add names only with permission.
  2. Open Club → Runs and add a local plan with its meeting point and date.
  3. Open the event and keep private local RSVP marks for runners you entered.
  4. Complete it with an optional recap or mark it canceled. Restore it later from History if needed.

Frequently asked questions

Does Run Clubbed use GPS?

No. Version 1.0 does not request location or background location. Distance is optional and manually entered when you finish.

How is pace calculated?

Pace is active timer seconds divided by the distance you entered. It is not GPS-verified and appears only when a valid manual distance exists.

Does the app invite or message runners?

No. Roster names and local RSVP marks are private, unverified records on your iPhone. Share every plan with your group yourself.

Does the app send reminders?

No. Version 1.0 does not schedule local notifications or send push notifications.

What happens if I leave the app during a run?

The active timer state is saved locally. Active segments use the iPhone monotonic system clock, so manual device-clock changes do not manufacture time. If the iPhone restarts or a clock discontinuity is detected, the app pauses the timer for review instead of guessing. Reopen Run to continue, finish, or discard.

How do I export my data?

Open More and choose Prepare JSON export, then Share prepared export. You choose the destination through the iOS share sheet.

What is a recovery archive?

If local data cannot be decoded, Run Clubbed preserves the original bytes locally and never shares them. Version 1.0 does not import or automatically repair that recovery snapshot. Delete All removes it.

How do I delete everything?

Open More, choose Delete all local data, and confirm. This clears the local roster, plans, receipts, active timer, and recovery copy. Delete previously exported copies from their destinations separately.

Safety and health limits

Run Clubbed is not an emergency monitor, safety service, medical device, or coach. It does not verify locations, attendance, distance, pace, or identity. Share plans directly, follow local conditions, and seek qualified guidance when needed.

Privacy
